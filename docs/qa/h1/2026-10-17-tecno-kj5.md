**Class.** Two documents define the reference phone differently: spec Q-17 says "Android 10+, 2–3 GB RAM,
entry-level SoC"; P5 §7 says "mid-range Android, 4 GB RAM, Snapdragon 6-series class". This phone has 4 GB, so it is
above the Q-17 class, but its Helio G85 is slower than a Snapdragon 6-series: it is **at least as demanding as the P5
§7 reference** for compute. The result is therefore used for the P5 §6 rule (a fail here is a fail on the
reference) and kept as "owner device" evidence for the Q-17 thresholds; a 2–3 GB phone is still needed for those.

**In-match Strategist compute.** The drift run plays real matches (natural racks, blanks included): compute p95 is

it shows real play sits above the bench figure.

## Decision consequence

- **P5 §6 switch rule triggers**: Strategist max over the H1 set including two-blank racks is 579 ms > 500 ms
  (about 2 % of two-blank positions exceed 500 ms; p99 555 ms). Per §6 the bots move to a worker runtime (ADR-0015,
  Bundle Mode, or option C), **or** the Strategist two-blank budget is reduced so the max stays ≤ 500 ms (a balance
  change: `/balance-check` and game-designer + ai-engineer sign-off). Decision pending; owners: solution-architect,
  ai-engineer, game-designer.
- **S4 (`bots.strategist.enabled`) stays off** until that decision is implemented and re-measured.
- Beginner (the only bot in the current build) is within every budget.
